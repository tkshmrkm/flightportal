自分用の入口ページ。人に見せるためではなく、スマホや出先からも自分が使うためのもの。

**それまでは、このリポジトリに置いたファイルは誰でもURLで取得できる**ので、下の「置かないもの」を守る。

## 置き場所の決め方

「どこから見たいか」ではなく「ファイルの中身に何が入っているか」で決める。迷ったら人に見せない側に置く。公開したものは、あとで消してもキャッシュや複製が残りうる。

| 区分 | 置き場所 | 開ける場所 | ポータルの札 |
|---|---|---|---|
| ログイン付き | 非公開リポジトリから Cloudflare Workers へ配備し、`private.mrkn55.com` の入口で Cloudflare Access が許可したメールアドレスだけを通す | スマホ・どのPCでも(ログイン後) | どこでも・🔑 ログイン・GitHub非公開 |
| 道具 | このリポジトリ。中身に個人のデータを持たない | スマホ・どのPCでも | どこでも |
| 非公開リポジトリ(PCのみ) | 非公開リポジトリを自宅PCのローカルサーバーで配る | 自宅PCのみ | PCのみ・GitHub非公開 |
| Gitなし | Git で管理しない自宅PCのフォルダを、ローカルサーバーで配る | 自宅PCのみ | PCのみ・Gitなし |

ポータルの札は3種類で、それぞれ別のことを表す。

- **開ける場所**: 「どこでも」(スマホ・どのPCでも開ける)か「PCのみ」(自宅PCのサーバーが動いているときだけ)。
- **置き場所**: 「GitHub非公開」(非公開リポジトリで履歴を残す)か「Gitなし」(自宅PCのフォルダだけ)。道具には付けない。
- **🔒 暗号化**: パスワードを入れるまで中身を読めない形で保存しているもの(カード情報)。置き場所とは別で、暗号化していないものはPCの中ではそのまま読める。
- **🔑 ログイン**: `private.mrkn55.com` に置き、許可したメールアドレスでログインした人だけが開けるもの(出張ページ、個人の視察予定)。カード情報と旅券の画像・番号は、ログインの内側にも置かない。

- **道具に置くもの**: 中身に個人の数値や記録が入っていない道具(FOP計算、LSP管理、為替コンバーターなど)。個人のデータは利用時に入力させてブラウザの localStorage に持つか、サーバー側に持つ。ブラウザで動くコードに API キーを書かない。
- LSP管理のクラウド保存は、`private.mrkn55.com` で開くと同じ住所の `/api/lsp` に、ログインだけで(APIキーなしで)保存する。公開版で開くと、従来どおり Worker `ancient-flower-7846` に APIキーで保存する。保存先のデータは同じ。
- **このリポジトリに置かないもの**: 自宅の地名や連絡先などの個人情報、予約番号や渡航書類、金額や資産、カード情報、会社料金、API キー、業務上の調査メモ。
- PCのみのリンクは、自宅PCが起動してサーバーが動いている間だけ開ける。スマホでは「PCのみを隠す」で隠せる。

## 更新の手順

1. `git pull` で最新にする(ほかの端末やセッションで更新していることがある)。
2. 編集する。ポータルにカードを足すときは、PCのみのものに `data-scope="pc"` と「PCのみ」の札を付け、置き場所の札(「GitHub非公開」か「Gitなし」)も付ける。暗号化して保存するものには「🔒 暗号化」、`private.mrkn55.com` のものには「🔑 ログイン」も付ける。
3. 差分を見て、上の「置かないもの」が入っていないか確かめる。
4. commit して push する(公開版の GitHub Pages への反映には数分かかる)。
5. `private.mrkn55.com` へ出す: `S:\work\private\inspection-private` で `node build-site.mjs` → `wrangler deploy`。このリポジトリのコミット済みの HEAD が入口(`/`)に入る。

PCのみのページの中身は、このリポジトリではなく自宅PCのフォルダで直接編集する。
