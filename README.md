# My Portal

https://tkshmrkm.github.io/flightportal/

自分用の入口ページ。このリポジトリは公開(GitHub Pages)なので、ここに置いたファイルは誰でも URL で取得できる。

## 置き場所の決め方

「どこから見たいか」ではなく「ファイルの中身に何が入っているか」で決める。迷ったら公開しない側に置く。公開したものは、あとで消してもキャッシュや複製が残りうる。

| 区分 | 置き場所 | 開ける場所 | ポータルの札 |
|---|---|---|---|
| 公開 | このリポジトリなどの GitHub Pages | スマホ・どのPCでも | どこでも |
| 非公開リポジトリ | 非公開リポジトリを自宅PCのローカルサーバーで配る | 自宅PCのみ | PCのみ・GitHub非公開 |
| Gitなし | Git で管理しない自宅PCのフォルダを、ローカルサーバーで配る | 自宅PCのみ | PCのみ・Gitなし |

ポータルの札は3種類で、それぞれ別のことを表す。

- **開ける場所**: 「どこでも」(公開ページ)か「PCのみ」(自宅PCのサーバーが動いているときだけ)。
- **置き場所**: 「GitHub非公開」(非公開リポジトリで履歴を残す)か「Gitなし」(自宅PCのフォルダだけ)。公開ページには付けない。
- **🔒 暗号化**: パスワードを入れるまで中身を読めない形で保存しているもの(カード情報)。置き場所とは別で、暗号化していないものはPCの中ではそのまま読める。

- **公開に置くもの**: 中身に個人の数値や記録が入っていない道具(FOP計算、LSP管理、通貨換算など)。個人のデータは利用時に入力させてブラウザの localStorage に持つか、鍵を Secret に置いたサーバー側に持つ。ブラウザで動くコードに API キーを書かない。
- **公開に置かないもの**: 自宅の地名や連絡先などの個人情報、予約番号や渡航書類、金額や資産、カード情報、会社料金、API キーやエンドポイント、業務上の調査メモ。スマホで見たくても、このリポジトリへ移さない。
- スマホから個人のデータを見たくなったときは、「ページは公開、データは鍵付きの別の場所」に分ける。
- PCのみのリンクは、自宅PCが起動してサーバーが動いている間だけ開ける。スマホでは「PCのみを隠す」で隠せる。

## 更新の手順

1. `git pull` で最新にする(ほかの端末やセッションで更新していることがある)。
2. 編集する。ポータルにカードを足すときは、PCのみのものに `data-scope="pc"` と「PCのみ」の札を付け、置き場所の札(「GitHub非公開」か「Gitなし」)も付ける。暗号化して保存するものには「🔒 暗号化」も付ける。
3. 差分を見て、上の「公開に置かないもの」が入っていないか確かめる。
4. commit して push する。GitHub Pages への反映には数分かかる。

PCのみのページの中身は、このリポジトリではなく自宅PCのフォルダで直接編集する。
